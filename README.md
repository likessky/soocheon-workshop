# 🛠️ 수천재작소 (SooCheon Workshop) v3.0
> **수천재의 개발 프로젝트 & 업무 자동화 도구 통합 관리 포털**

구글 스프레드시트에 프로젝트 내용만 적으면, 대시보드에 실시간으로 프로젝트가 전시되는 하이브리드 포털입니다.
이제는 시트를 직접 열지 않고도 **웹 화면에서 바로 등록·수정·삭제**가 가능하고, 분류 탭도 화면에서 관리할 수 있습니다.

---

## 🌟 v3.0에서 달라진 점

1. **웹 화면에서 바로 등록 / 수정 / 삭제**
   - 카드에 마우스를 올리면(모바일은 항상) ✏️ 수정, 🗑 삭제 아이콘이 나타납니다.
   - 상세 보기 모달에서도 동일하게 수정/삭제할 수 있습니다.
   - 모든 변경은 즉시 구글 시트에도 반영됩니다.
2. **탭(카테고리) 화면 관리**
   - 탭 목록 옆 ⚙️ 버튼으로 탭을 추가·이름/색상 변경·순서 변경·삭제할 수 있습니다.
   - 탭 이름을 바꾸면 그 탭에 속한 프로젝트들의 분류도 자동으로 따라 바뀝니다.
   - 탭을 삭제하면 그 안의 프로젝트를 다른 탭으로 옮긴 뒤 삭제합니다 (프로젝트가 사라지지 않습니다).
3. **즉시 로딩 (체감 속도 개선)**
   - 마지막으로 불러온 목록을 브라우저에 저장해두고, 재접속 시 그 즉시 화면에 표시한 뒤
     뒤에서 조용히 최신 정보로 갱신합니다. 접속할 때마다 뜨던 "연동 중" 알림 창도 사라졌습니다.
4. **가로(열) 개수 조절**
   - 세로 표시 개수(6/12/24/전체)뿐 아니라, 한 줄에 보일 카드 수(자동/1~5열)도 취향대로 조절할 수 있습니다.
5. **모바일 최적화 레이아웃**
   - 히어로 제목이 화면 폭에 맞게 자연스럽게 줄바꿈됩니다.
   - 통계 카드가 가로로 스와이프되는 칩 형태로 바뀌어 화면을 덜 차지합니다.
   - 카드가 썸네일-내용이 나란히 배치된 컴팩트한 가로형으로 바뀝니다.
   - 화면 우측 하단에 플로팅 [+] 버튼으로 어디서든 바로 등록할 수 있습니다.

> ⚠️ **보안 안내**: 현재 Apps Script 웹앱은 "모든 사용자" 접근을 허용하며, 별도의 비밀번호나
> PIN 확인 없이 등록/수정/삭제 요청을 처리합니다. 배포된 웹앱 주소를 아는 사람은 누구나
> 데이터를 변경할 수 있으니, URL을 외부에 공개하지 않도록 주의하세요.

## 📂 파일 구조

```text
수천재작소/
├── index.html                  # 메인 대시보드 (반응형 레이아웃, 컨트롤 바, 각종 모달)
├── style.css                   # 스타벅스 감성 디자인 시스템 (카드/리스트 뷰, 반응형, 스켈레톤)
├── app.js                      # 검색/필터/페이지네이션/뷰모드/CRUD/캐시 로딩 메인 로직
├── config.js                   # 기본 설정 (시트 URL, 첫 로딩 전 임시 기본 탭)
├── google-apps-script/
│   └── Code.gs                 # 구글 시트 CRUD API (읽기/등록/수정/삭제, 탭 관리)
└── README.md                   # 본 사용 가이드 문서
```

## 🚀 구글 스프레드시트 연동 가이드

### [1단계] 프로젝트 시트 준비

기존에 쓰던 시트를 그대로 사용하면 됩니다. **1행(헤더)**에 아래 9개 항목이 있으면 되고,
비어 있거나 형식이 조금 달라도 Code.gs가 배포 시 알아서 정리합니다.

| 열 | A | B | C | D | E | F | G | H | **I** |
|---|---|---|---|---|---|---|---|---|---|
| **항목** | **웹사이트 URL** | **제목** | **설명** | **썸네일 URL** | **카테고리** | **운영 상태** | **다운로드 링크** | **기술 스택** | **고유 ID (자동 생성)** |

> 💡 **I열(고유 ID)은 직접 입력하지 마세요.** 웹앱이 처음 접속할 때 빈 칸을 자동으로 채웁니다.
> 이 ID 덕분에 시트에서 행 순서를 바꾸거나 다른 행을 지워도 수정/삭제가 엉뚱한 행에 적용되지 않습니다.

`카테고리`라는 이름의 시트도 함께 자동으로 생성됩니다 (이름/아이콘/색상/순서/ID). 웹 화면의
⚙️ 탭 관리 기능으로 편집하는 것을 권장하지만, 시트에서 직접 수정해도 됩니다.

### [2단계] Apps Script 웹 앱 배포하기

1. 스프레드시트 상단 메뉴 **[확장 프로그램] > [Apps Script]** 클릭
2. 기존 코드를 모두 지우고 `google-apps-script/Code.gs`의 **전체 내용을 붙여넣기**한 뒤 저장(`Ctrl+S`)
3. **이미 배포된 주소가 있는 경우 (기존 사용자)**
   - 우측 상단 **[배포] > [배포 관리]** 클릭
   - 기존 배포 항목의 ✏️(연필) 아이콘 클릭 → **버전: "새 버전"** 선택 → **[배포]**
   - ⚠️ 여기서 **[새 배포]**를 누르면 URL이 새로 생기니 반드시 **[배포 관리 > 수정]** 경로를 사용하세요.
4. **처음 배포하는 경우**
   - **[배포] > [새 배포]** → 유형: **웹 앱** 선택
   - 다음 사용자 권한으로 앱 실행: `나(사용자 계정)` / 액세스 권한: **모든 사용자**
   - **[배포]** 후 생성된 웹 앱 URL을 복사

### [3단계] 웹 포털에서 연결하기

1. `index.html`을 브라우저로 엽니다 (또는 Vercel 배포 주소로 접속).
2. 우측 상단 **[시트 연동]** 버튼을 클릭합니다.
3. 웹 앱 URL을 붙여넣고 **[저장 및 실시간 동기화]**를 누르면 끝!
   - 이후에는 `config.js`의 `SHEET_API_URL`을 기본값으로 미리 넣어두면, 방문자가 별도 설정 없이도
     바로 연결된 상태로 접속합니다.

## ✏️ 웹 화면에서 프로젝트 관리하기

- **등록**: 우측 상단(또는 모바일 하단 플로팅) **[+]** 버튼 → 정보 입력 → [구글 시트로 전송!]
- **수정**: 카드에 마우스를 올리거나(모바일은 항상 표시) ✏️ 아이콘 클릭, 또는 상세 보기 모달의 [수정] 버튼
- **삭제**: 🗑 아이콘 클릭 → 확인 모달에서 [삭제] (구글 시트의 해당 행도 함께 삭제됩니다)
- **탭 관리**: 카테고리 탭 줄 오른쪽 ⚙️ 버튼 → 추가 / 이름·색상 변경 / 순서 변경 / 삭제

---

## 🔧 문제 해결

- **등록/수정/삭제가 안 돼요**: [시트 연동]에 등록한 URL이 최신 Code.gs로 재배포된 주소인지 확인하세요.
  (구버전 Code.gs는 `doPost`가 등록만 지원하고 수정/삭제 action을 처리하지 못합니다.)
- **재배포했더니 갑자기 안 붙어요**: [새 배포]를 눌러 URL이 바뀐 경우입니다. [시트 연동]에서 새 URL로
  다시 저장해주세요.
- **카드에 아이디가 없다고 나와요 / 수정이 안 돼요**: 웹앱을 한 번 새로고침해 I열에 고유 ID가
  자동으로 채워지도록 해주세요 (최초 1회, 데이터가 많으면 몇 초 걸릴 수 있습니다).
