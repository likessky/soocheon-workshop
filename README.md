# 🛠️ 수천재작소 (SooCheon Workshop) v2.0
> **수천재의 개발 프로젝트 & 업무 자동화 도구 통합 관리 포털**

구글 스프레드시트에 프로젝트 내용만 적으면, 안티그래비티 대시보드에 실시간으로 프로젝트가 전시되는 하이브리드 포털입니다.  
복잡한 외부 AI API나 어려운 수식 없이, 누구나 메모장 쓰듯이 초간단하게 관리할 수 있습니다.

---

## 🌟 주요 특징 (v2.0 업데이트)

1. **초간단 데이터 관리 (API/복잡한 수식 완전 제거)**
   - API 키나 체크박스 없이, 시트에 사이트 주소(URL)와 제목, 설명만 적으면 즉시 연동됩니다.
   - 복사해서 붙여넣을 복잡한 수식이 전혀 없어 누구나 1분 만에 세팅 가능합니다.
2. **화면 표시 개수 조절 (스마트 페이지네이션)**
   - 한 화면에 표시할 개수를 자유롭게 선택할 수 있습니다 (`6개씩`, `12개씩`, `24개씩`, `전체보기`).
   - 깔끔한 페이지 번호 버튼과 이전/다음 이동 바를 지원합니다.
3. **보기 형태 자유 전환 (카드 뷰 ↔ 리스트 뷰)**
   - 🔲 **카드 그리드 뷰**: 비주얼과 썸네일 중심의 감성적인 카드 형태
   - 📋 **리스트 목록 뷰**: 한 줄씩 깔끔하게 나열되어 수십 개의 사이트를 한눈에 빠르게 파악하고 바로 접속/다운로드할 수 있는 형태
   - 사용자가 선택한 보기 형태와 개수는 브라우저에 자동 저장됩니다.
4. **고성능 반응형 대시보드 (모바일 친화적)**
   - 스마트폰, 태블릿, PC 어디서나 깨짐 없이 최적화된 반응형 레이아웃.
   - 스타벅스 크림 라이트 & 리저브 다크 테마 원클릭 전환.
5. **실시간 검색 & 필터링**
   - 검색창 입력 시 즉시 필터링 (프로젝트명, 설명, 태그 실시간 검색).
   - 카테고리 탭 (`전체`, `웹사이트`, `프로그램`, `스크립트`) 및 운영 상태 필터.

## 📂 파일 구조

```text
수천재작소/
├── index.html                  # 메인 대시보드 (반응형 레이아웃, 컨트롤 바, 모달)
├── style.css                   # 스타벅스 감성 디자인 시스템 (카드/리스트 뷰, 페이지네이션)
├── app.js                      # 검색/필터/페이지네이션/뷰모드/시트 연동 메인 로직
├── config.js                   # 기본 설정 및 초기 데모 샘플 데이터셋
├── google-apps-script/
│   └── Code.gs                 # 구글 시트 데이터를 초고속 JSON으로 전송하는 Apps Script
└── README.md                   # 본 사용 가이드 문서
```

## 🚀 구글 스프레드시트 초간단 연동 가이드 (3단계)

### [1단계] 스프레드시트 1행 헤더 만들기
새 구글 스프레드시트를 하나 만들고, **1행(헤더)**에 다음과 같이 7개 항목을 차례대로 입력합니다:

| 열 | A | B | C | D | E | F | G | H (선택) |
|---|---|---|---|---|---|---|---|---|
| **항목** | **웹사이트 URL** | **프로젝트 제목** | **프로젝트 설명** | **썸네일 URL** | **카테고리** | **운영 상태** | **다운로드 링크** | **기술 스택** |

> 💡 **작성 팁**:
> - **A열 (URL)**: 사이트 바로가기 주소를 입력합니다.
> - **B열 (제목)**: 프로젝트 이름을 입력합니다.
> - **C열 (설명)**: 프로젝트에 대한 간단한 설명을 입력합니다.
> - **D열 (썸네일)**: 이미지 주소를 넣습니다. (비워두면 예쁜 기본 이미지가 자동 적용됩니다!)
> - **E열 (카테고리)**: `웹사이트`, `프로그램`, `스크립트` 중 하나를 적습니다. (비워두면 `웹사이트`)
> - **F열 (운영 상태)**: `운영 중`, `업데이트 중`, `다운로드 전용` 중 하나를 적습니다. (비워두면 `운영 중`)
> - **G열 (다운로드 링크)**: 구글 드라이브 다운로드 주소가 있다면 입력합니다. (없으면 비워두기)

---

### [2단계] Apps Script 웹 앱 배포하기
1. 스프레드시트 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 기존에 적혀있는 코드를 모두 지우고, `google-apps-script/Code.gs` 파일의 **전체 내용을 복사하여 붙여넣기**한 뒤 저장(`Ctrl + S`)합니다.
3. 우측 상단의 파란색 **[배포] > [새 배포]** 버튼을 클릭합니다:
   - **유형 선택**: 톱니바퀴 아이콘 > **웹 앱** 선택
   - **설명**: `수천재작소 API` 입력
   - **다음 사용자 권한으로 앱 실행**: `나 (사용자 계정)`
   - **액세스 권한이 있는 사용자**: **모든 사용자 (Anyone)** (★ 필수: 그래야 로그인 없이 포털에서 읽을 수 있습니다)
   - **[배포]** 버튼을 누른 뒤 나타나는 **웹 앱 URL**을 복사합니다.

---

### [3단계] 웹 포털에서 연결하기
1. 브라우저에서 `index.html`을 실행합니다.
2. 우측 상단의 **[시트 연동]** 버튼을 클릭합니다.
3. [2단계]에서 복사한 웹 앱 URL을 붙여넣고 **[저장 및 실시간 동기화]**를 누르면 끝!
   - 상단 인디케이터에 초록불(🟢)이 켜지며 시트에 적어둔 내용이 즉각 화면에 나타납니다.
